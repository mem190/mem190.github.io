1.2 本应用是面向成年人的个人屏幕时间自我管理工具，帮助用户为本人设备上的选定应用设置每日可用时长、允许使用时间段，并在达到条件后通过系统级能力进行提醒与限制。

二、服务内容

在您授权并完成设置后，本应用可提供包括但不限于以下功能：

  • 申请并使用 Apple Screen Time / Family Controls 等相关系统能力；
  • 选择需要自律管理的应用，并设置每日目标、允许使用时间段等；
  • 在达到目标或超出允许时段后，通过系统屏蔽等方式限制继续使用；
  • 通过完成学习、运动、阅读等任务获得继续使用时长；
  • 通过本机修改密码、Face ID / 触控 ID 等方式验证身份后调整设置或暂停当日自律；
  • 在本机查看使用情况、任务进度及相关设置。
