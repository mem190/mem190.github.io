隐私政策

适用产品：别刷太久（SelfLock） | 更新日期：2026年9月22日 | 生效日期：2026年9月22日

摘要：本应用以本地处理为原则。核心自律功能不依赖联网；您的自律配置、使用时长与任务数据默认仅保存在本机；我们不收集、不上传、不出售、不分享您的 Screen Time 使用数据用于广告或画像。

「别刷太久」（以下简称「本应用」或「我们」）重视您的隐私。本《隐私政策》说明我们如何处理与本应用相关的信息。请在使用前仔细阅读。您使用本应用，即表示您知悉并同意本政策；如不同意，请停止使用。

一、我们是谁 / 政策适用范围

1.1 本政策适用于「别刷太久」iOS 客户端及其相关扩展组件（如 Device Activity Monitor、Shield Configuration、Device Activity Report 等）。

1.2 本应用是个人屏幕时间自我管理工具，授权模式为个人设备自我管理（Individual），并非以监控他人或儿童设备为核心用途的家长控制产品。

二、我们处理的信息

为实现自律管理功能，本应用可能在您的设备本地处理以下信息：

信息类型 示例 处理目的 存储位置
自律配置 所选应用令牌、每日目标时长、允许使用时间段、是否启用限制等 执行您设定的自律计划 本机（App Group / 本地存储）
使用相关数据 当日/近期使用时长快照、是否达到目标、锁定状态等 展示进度、触发休息与屏蔽 本机
任务数据 默认任务/专属任务、完成进度、奖励分钟数等 通过完成任务继续当日目标 本机
安全验证信息 修改密码哈希、临时解锁/今日暂停相关状态 防止轻易绕过自律约定 本机；密码以哈希形式保存，不以明文存储
偏好设置 语言、通知开关等 改善使用体验 本机
系统权限状态 屏幕使用时间授权结果、通知授权状态等 判断功能是否可用并给出指引 由系统管理 / 本机读取

说明：通过 FamilyControls 选择的应用以系统令牌形式处理，本应用无法也不尝试获取您所选应用的详细隐私内容或账号密码。

三、我们如何使用信息

我们仅在以下目的范围内使用上述本地信息：

  • 提供、维护与改进自律限制、任务解锁、暂停自律等核心功能；
  • 在应用内向您展示使用与任务进度；
  • 在您开启通知时，发送与自律相关的本地提醒；
  • 保障设置修改、密码重置等场景下的身份验证安全；
  • 履行法律法规规定的义务。

四、我们不会做什么

  • 不收集、不上传、不分享您的 Screen Time 使用明细用于广告、画像或向第三方出售；
  • 核心自律功能不依赖联网，不以「必须登录云端账号」为使用前提；
  • 不将生物识别原始数据上传至我们的服务器（Face ID / 触控 ID 由系统在本机完成验证）；
  • 不以监控他人设备作为产品核心目的。

五、权限说明

5.1 屏幕使用时间 / Family Controls

用于选择应用、监测使用阈值、在达到条件后进行系统级屏蔽与展示自定义提示。您可在系统设置中管理授权。未授权时，相关功能不可用。

5.2 Face ID / 触控 ID

用于修改自律计划、暂停今日自律、重置修改密码等场景的本机身份验证。我们无法获取您的面容或指纹原始数据。

5.3 通知（如开启）

用于发送与目标达成、时间段限制等相关的本地通知。您可随时在系统设置中关闭。

六、信息存储与期限

6.1 上述业务数据默认存储于您的设备本地（含 App Group 共享容器，以便主应用与系统扩展协同工作）。

6.2 存储期限为：实现功能所必需的期间，或直至您删除相关配置、清除数据或卸载应用。

6.3 卸载应用、更换设备或清除 App 数据后，本地数据可能无法恢复。

七、信息共享、转让与公开披露

除以下情形外，我们不会向第三方共享您的本地自律与使用数据：

  • 获得您的明确同意；
  • 根据法律法规、诉讼、仲裁或行政管理部门的强制要求；
  • 为保护您、他人或公共利益所必需，且符合法律规定。

如未来引入可选的云同步、统计分析或客服等需要传输数据的能力，我们将另行告知并在必要时重新征求同意。

八、未成年人保护

本应用主要面向具有完全民事行为能力的成年人进行自我管理。若您为未成年人，请在监护人指导下阅读本政策并使用本应用。我们不会主动收集未成年人的个人信息用于营销。

九、您的权利

在适用法律允许的范围内，您可以：

  • 在应用内查看、修改或删除自律清单与相关设置；
  • 关闭屏幕使用时间、通知、Face ID 等系统权限；
  • 通过卸载应用停止我们对本机数据的处理；
  • 就隐私问题通过下文联系方式与我们沟通。

十、安全措施

我们采取合理的技术与管理措施保护本地数据，例如：修改密码以哈希形式存储、利用系统沙盒与 App Group 权限边界、生物识别交由系统本地处理等。但请理解，任何安全措施都无法保证绝对安全。

十一、第三方服务与系统能力

本应用依赖 Apple 系统及 Screen Time 相关框架。Apple 对系统能力与数据的处理适用 Apple 的隐私政策与条款。我们无法控制 Apple 系统本身的数据处理方式。

十二、政策更新

我们可能适时修订本政策。更新后将通过应用内展示、桌面/网站发布或其他合理方式告知。若更新涉及重大变更（如处理目的、方式发生实质变化），我们将按法律法规要求另行提示或征得同意。

十三、联系我们

如您对本政策或个人信息处理有疑问、投诉或建议，可通过应用内「我的」相关入口，或发送邮件至 BestZeng1250@163.com 与我们联系。我们将在合理期限内予以答复。
